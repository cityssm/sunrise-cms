# Statutory Holiday Management

Statutory Holiday Management configures the holidays used to calculate work
order due dates and milestone dates. The page is available under Administrator
Tools.

## Holiday Source

Choose a country, state or province, and region to load holidays from the
configured holiday source. Select the types of holidays that should be
included, then save the source configuration.

The available country and region values depend on the holiday data provider
configured for the application.

## Additional Holidays

Use **Additional Holiday Dates** to add organization-specific holidays that are
not supplied by the configured source. Dates can be added or removed from this
section.

Package holidays can be ignored by using **Ignore** in the Upcoming Stat
Holidays table. Ignored dates appear in the **Ignored Stat Holiday Dates**
section and can be restored with **Unignore**. Saving changes updates the
holiday dates used by work order calculations.
