# Burial Site Type Management

![Burial Site Type Management](images/burialSiteTypeManagement.png)

Burial site types classify the spaces managed in each cemetery. Use them to
represent common layouts such as graves, mausoleum crypts, niches, and urn
gardens.

## Managing Types

Use **Add Burial Site Type** to create a type. Each type can have the following
properties:

- **Burial Site Type**: The name shown throughout Sunrise CMS.
- **Maximum Body Capacity**: The default maximum number of bodies that a burial
  site of this type can hold.
- **Maximum Cremated Capacity**: The default maximum number of cremated remains
  that a burial site of this type can hold.
- **Available on Portal**: Whether burial sites of this type can be made
  available through an enabled external portal integration.

Use the edit controls to update a type or change its display order. Deleting a
type removes it from the list and is restricted if it is still being used.

## Custom Fields

Each burial site type can have its own custom fields. Expand a type to add
fields, and choose the field name and type needed for the site's additional
information.

Custom field values are entered on the burial site edit page. Fields can be
reordered or removed from the burial site type.
