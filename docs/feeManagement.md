# Fee Management

![Fee Management](images/feeManagement.png)

Fee Management maintains the fees that can be added to contracts. Fees are
organized into categories and can be limited to selected contract types and
burial site types.

## Fee Categories

Use **Add Fee Category** to create a category, such as Opening and Closing or
Monument Services. Categories can be renamed, reordered, or removed.

## Fees

Expand a fee category to add a fee. A fee can include:

- A name and description.
- A tax percentage.
- A fixed fee amount.
- Contract type and burial site type restrictions.

Use the edit controls to update a fee, change its amount, or reorder it within
the category. Removing a fee does not alter fees that have already been added
to existing contracts.

When a restricted fee is not applicable to a contract or burial site, it will
not be offered for selection.
