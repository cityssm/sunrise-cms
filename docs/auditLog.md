# Audit Log

The Audit Log records changes to supported records when audit logging is
enabled. It is available in Administrator Tools only when the
`settings.auditLog.enabled` setting is enabled.

## Reviewing Changes

Filter the log by date range, record type, and username. The results show the
changes that match the selected filters.

The record-type filter includes burial sites, cemeteries, contracts, contract
types, fees, work orders, users, and configuration tables.

## Purging the Audit Log

Use **Purge Audit Log** to remove old audit entries. Purging follows the audit
log retention period configured by the application. This action permanently
removes matching entries and cannot be undone.
